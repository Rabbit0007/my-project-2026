Date: 2026-05-29
Task: 90

1. DATA FLOW TRACE:
   UserController.search(HttpServletRequest)
     -> String orderBy = request.getParameter("orderBy")
     -> UserService.search(keyword, orderBy)
       -> UserMapper.search(keyword, orderBy)
         -> UserMapper.xml: ORDER BY ${orderBy}

2. VULNERABLE PATTERN IDENTIFIED:
   File: /workspace/input/extracted/src/main/resources/mapper/UserMapper.xml
   Line 6: ORDER BY ${orderBy}
   
   MyBatis Syntax Analysis:
   - #{keyword} = prepared statement parameter (SAFE)
   - ${orderBy} = string interpolation (VULNERABLE)
   
   The ${} syntax performs direct string substitution without escaping,
   allowing arbitrary SQL to be injected via the orderBy request parameter.

3. ATTACK SURFACE:
   Endpoint: UserController.search()
   Parameter: orderBy
   Payload Example: orderBy=id; DROP TABLE users;--
   
   This would result in:
   SELECT id, name FROM users WHERE name LIKE CONCAT('%', ?, '%') ORDER BY id; DROP TABLE users;--
