## Vulnerability Confirmed

### SQL Injection in ORDER BY Clause
File: /workspace/input/extracted/src/main/resources/mapper/UserMapper.xml
Line: 7 (ORDER BY ${orderBy})

Vulnerable Code:
```xml
ORDER BY ${orderBy}
```

Issue: Uses MyBatis string interpolation (${...}) instead of parameter binding (#{...})
- ${orderBy} = direct string substitution = SQL INJECTION
- #{keyword} = prepared statement parameter = SAFE

Attack Vector:
- orderBy parameter is passed from UserController -> UserService -> UserMapper
- No sanitization or whitelist validation observed
- Attacker can inject: orderBy="id; DROP TABLE users--"
