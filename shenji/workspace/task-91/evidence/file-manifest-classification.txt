## Identified Attack Surfaces
1. SQL Injection in UserController.search() via orderBy parameter
   - Path: UserController.search() -> UserService.search() -> UserMapper.search() -> UserMapper.xml ${orderBy}
   - The orderBy parameter is passed directly to SQL ORDER BY clause via ${orderBy}
   - MyBatis ${} syntax performs string interpolation, not parameterization

2. Admin Export functionality in AdminExportController.export()
   - Path: AdminExportController.export() -> AdminExportService.exportUsers()
   - Parameters: format, includeInactive
   - Potential for data exfiltration or format-based attacks
